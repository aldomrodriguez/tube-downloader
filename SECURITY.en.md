# Security policy

[🇦🇷 Español](SECURITY.md) · 🇬🇧 **English**

## Supported versions

Only the latest version published in
[Releases](https://github.com/aldomrodriguez/tube-downloader/releases/latest) receives
fixes. The app updates itself, so the way to get a fix is to accept the update when it's
offered.

## How to report a vulnerability

**Don't open a public issue.** Use GitHub's
[private reporting](https://github.com/aldomrodriguez/tube-downloader/security/advisories/new)
or write through [aldorodriguez.com.ar](https://aldorodriguez.com.ar).

Include, if you can:

- which version you're using,
- what can be done with the vulnerability and what it takes to exploit it,
- the steps to reproduce it.

You'll get a reply within 7 days. Once it's fixed, the fix ships as a new version and,
if you want, you're credited in the notes.

## Of particular concern

The auto-updater downloads and runs a file from the internet, so any way of making it
install an executable other than the one published in this repository is considered
serious.
